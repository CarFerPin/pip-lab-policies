Política de privacidad — PIP Lab

Última actualización: 28 de septiembre de 2026

Inicio Eliminación de datos

PIP Lab es una herramienta de gestión y automatización utilizada para administrar contenidos y conexiones con servicios externos, entre ellos Facebook.

Cuando un usuario conecta una cuenta de Facebook o una Facebook Page con PIP Lab, la aplicación puede recibir y utilizar únicamente la información necesaria para establecer y mantener esa conexión, como:

  • identificadores de cuenta o Page;
  • nombre de la Page;
  • permisos o capacidades concedidos por Meta;
  • tokens de acceso proporcionados mediante los mecanismos oficiales de Meta.

PIP Lab utiliza esta información exclusivamente para realizar las funciones autorizadas por el usuario, como verificar la conexión con una Facebook Page y, cuando corresponda, publicar contenido autorizado por el usuario.

Los tokens y credenciales sensibles no se publican ni se almacenan en repositorios de código. En la aplicación de escritorio, las credenciales sensibles se almacenan mediante el almacén seguro de credenciales del sistema operativo.

PIP Lab no vende datos personales ni los comparte con terceros con fines publicitarios.

La información obtenida mediante las APIs de Meta se utiliza únicamente de acuerdo con los permisos otorgados por el usuario y con las políticas aplicables de Meta.

El usuario puede revocar el acceso de PIP Lab desde la configuración de su cuenta de Facebook o solicitar la eliminación de la información asociada a la conexión.

Para consultas relacionadas con privacidad o eliminación de datos, puede contactar a carferpinilla@hotmail.com.
