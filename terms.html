PIP Lab es una herramienta de gestión y automatización diseñada para ayudar a administrar contenidos y conexiones con servicios externos, entre ellos Meta/Facebook.

Uso autorizado

El usuario debe utilizar PIP Lab únicamente con cuentas, Pages y servicios para los que tenga autorización legítima. El usuario es responsable de los contenidos que publique o gestione mediante PIP Lab.

Servicios de terceros

PIP Lab puede conectarse con plataformas de terceros mediante sus APIs y mecanismos oficiales de autenticación. El uso de esas integraciones también está sujeto a las condiciones y políticas de cada proveedor externo.

Credenciales y acceso

PIP Lab no requiere que el usuario publique ni comparta sus credenciales sensibles. Cuando corresponde, los tokens de acceso se almacenan mediante el almacén seguro de credenciales del sistema operativo.

Disponibilidad

PIP Lab puede depender de servicios externos. Cambios, interrupciones, límites o restricciones aplicadas por terceros pueden afectar temporalmente algunas funciones.

Privacidad y eliminación de datos

La información sobre tratamiento de datos está disponible en la Política de privacidad. Las instrucciones para solicitar eliminación de datos están disponibles en Eliminación de datos.
